# Machine Learning experiments

This repository contains working notes (in the form of Jupyter Notebooks) as I teach myself various Machine Learning techniques.

To replicate these results you will need:

- a Python environment manager (I use [Anaconda](https://www.anaconda.com/download), which also installs the relevant versions of Python)
- an Anaconda environment based on the `environment.yml` file in this repo
- [Visual Studio Code](https://code.visualstudio.com/) with the recommended extensions installed
